# CHAT AI

تطبيق مساعد ذكاء اصطناعي متعدد الأدوات، يبدأ بإصدار Android باستخدام Flutter.

## التقنية
- Flutter / Dart
- Firebase Authentication و Cloud Firestore (يتم ربطهما بعد إعداد المشروع)
- Backend آمن لاستدعاء مزودي الذكاء الاصطناعي
- Google Play Billing للاشتراكات داخل Android

## الأمان
لا تضع مفاتيح API أو ملفات Firebase الخاصة أو مفاتيح التوقيع داخل المستودع العام.
